## Принципы

1. Новое решение получает ID и статус PROPOSED/APPROVED/SUPERSEDED; изменение существующего решения явно фиксируется.
2. При конфликте приоритет: последнее явно APPROVED решение → [REQUIREMENTS](REQUIREMENTS.md) → [DOMAIN-CONTRACTS](DOMAIN-CONTRACTS.md) → проектные предложения.
3. Любая модель состояний, денежная политика, права покупателя и правовая часть Казахстана проходят S2/legal review до реализации.
4. DEC-27 **отменяет старые требования SMS/OTP и подтверждённого телефона**. Web Lead без OTP, phone-as-login UNVERIFIED.
5. DEC-19…23, 24…27 не отменяют границы продукта: Flutter Favorite не равно Seller Inbox bookmark, Web callback не Order, trade tier не star rating.

- **DEC-30 / APPROVED direction:** ночной расчёт за предыдущий период после полуночи; 00:30 Asia/Almaty — предложенное расписание, cutoff 00:00.
- **DEC-31 / APPROVED direction:** личные данные и их основные хранилища размещаются в Казахстане, используется выборочное шифрование и разграничение доступа. Третьи стороны/трансграничные передачи и юридические требования проверяются до релиза.
- **DEC-32 / PROPOSED:** цены в KZT считать BigDecimal с двухзначным денежным итогом; отдельно показывать округление общей суммы для наличных в соответствии с правом РК, без заявлений о фактической оплате.

## DEC-34 — SMS provider только для восстановления доступа

**APPROVED scope:** SMS запрещён для регистрации, обычного входа, торговых операций, внутренних уведомлений и QR-подтверждения получения. Предусмотреть сменный интерфейс `PhoneVerificationProvider` **исключительно в recovery-модуле**, без обязательной инфраструктурной зависимости для обычного использования. **Security gate:** отправка SMS и успешная проверка кода сами по себе не разрешают восстановление аккаунта, если номер до этого не был надёжно привязан к данному аккаунту. Для неподтверждённых номеров recovery по телефону выключен. При наличии подтверждённого email доступно восстановление по email. Как установить доверенную привязку без SMS при регистрации и предотвратить account squatting — OPEN-15, не решено.
