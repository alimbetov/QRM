## Принципы сохранения решений

1. Новое решение получает идентификатор и статус `PROPOSED / APPROVED / SUPERSEDED`.
2. Код и тесты не реализуют спорную трактовку молча; требуется зафиксировать oracle.
3. Денежные условия и права покупателя проверяются юридически применительно к Казахстану до production.
4. При конфликте первично **последнее явно принятое** DEC-решение, затем [REQUIREMENTS.md](REQUIREMENTS.md), далее проектные предложения.
